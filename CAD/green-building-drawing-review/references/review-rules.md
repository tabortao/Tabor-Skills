# 绿建施工图内审 · 判定口径（每次审查前必读）

## 0. 权威顺序（冲突时的取舍）

1. **用户审核后的「内审意见最终版」**：若项目目录存在，最高优先级，用于校准措辞、条数与技术数值。
2. **本项目《XX绿色建筑设计建议 V3.x》原文**：唯一的条文与指标依据。
3. **本项目 CAD 图纸文字**：判定「已落实 / 缺档 / 数值不符」的唯一证据。
4. **参考《审图记录单》模板**：只提供版式、意见条数基准、差错分类惯例。其中的**规范版本、指标数值、旧项目名、已填的处理/验证栏一律不可信**。
5. 通用规范知识：仅用于理解条文，不得用来新增意见。

> 已验证的模板陷阱：`20250603 给排水`模板 7.2.10 写坐便器 4L/5L 且无 GB 25502-2024；本项目建议书 V3.1 为 3.8L/4.8L + GB 25502-2024。照抄模板数值即出错。

## 1. 逐条判定算法

对每个专业，以「参考模板意见条数」为基准逐条走查，再补建议书新增项：

```
模板每条意见  → 在本项目图纸中检索证据
   ├─ 图纸已有等效表述（含数值达标）  → 删除，不提
   └─ 图纸缺失 / 数值不符 / 标准版本旧 / 只写了部分  → 保留，按建议书原文重写
建议书每条要求 → 在图纸中检索证据
   ├─ 图纸已落实                      → 不提
   ├─ 属于永久排除项                  → 不提（见 §2）
   └─ 图纸缺 / 建议书 3.3「需提供资料」→ 新增一条意见
最后 → 跨专业去重（§5）→ 重算小计与分类勾选（§3）
```

**「已落实」的判定标准**：图纸有等效文字或等效指标即可，不要求逐字一致；只提「缺档 / 数值不符 / 标准版本旧 / 完全缺失」四种情形。图纸沿用旧项目名、非绿建范围的图面错漏，不提。

**「缺档」写法**：图纸写了基准值但缺提高档时，只补缺的那一档，不要整条重写。例如电气 5.1.5 图纸已有 SVM≤1.3，只提「儿童青少年长时间学习活动场所 SVM≤1.0」；建筑外窗已有 35dB/30dB，只提「非临街朝交通干线卧室外窗 Rw+Ctr≥33dB」。提出缺档时要写明**项目事实依据**（如「因项目有幼儿园，需要补充修改」），让设计院知道为什么本项目适用。

**最终交付格式**：用户会按版面手工删减空白意见行，但各专业留白不一致（建筑 36→29 删光、给排水留 2 行、电气留 4 行、暖通未动），没有统一规律。**默认保留模板原行数**；仅在用户要求或版面过长时用 `trim_rows.py --keep-blank N` 计算待删行，填表保存后从大到小逐行删，删完重新核对小计/签署行。

## 2. 永久排除项（用户长期规则，一律不提给各专业）

用户是绿建专业负责人，以下 5 类由用户自行出专项报告，**审图记录单 / 提资意见中一律不出现**：

1. 可循环材料用量占建筑总耗材重量＞10% 及其计算书（第 7.2.17.1 条）
2. 全装修交付与「与土建无关的家具、电器不作交楼验收标准」的协调（第 3.2.8.1 条）
3. 住宅装饰性构件造价与总造价比例≤2%（第 7.1.9 条）
4. 居住街坊集中绿地 GB 55038-2025 第 3.2.2 条强条：人均≥0.50㎡、宽≥8m、日照阴影线外≥1/3、老幼活动场地（第 8.2.3 条）
5. 每单体至少一处楼梯间天然采光及良好视野、自行车停车位、绿化率达规划指标 105% 并在绿化专篇/总图指标表体现（第 6.2.5.4、6.1.4、8.2.3.1 条）

> 填写《绿建设计建议》「落实情况」内部台账时，这些仍按图纸实际写「需补充修改」，并注明「由绿建专业负责人专项报告处理，不列入提资意见」。**台账 ≠ 提资意见，两者不可混用**。

## 3. 审图记录单写作口径（据用户审核后的最终版）

1. **一条意见只对应一个条款**，复合条款拆成多条独立意见。
2. **直接照抄设计建议原文**，用「设计说明增加：……」或「图纸表达：……」，**末尾带条文号**「（第 X.X.X 条）」。
3. **不追加衍生要求**：计算书、使用部位、甲方决策、厂家检测报告、构造做法表逐项标注等，除非建议书原文就有。
4. **不追加规范体系核查**：如复核地方标准有效性、明确星级目标；设计依据只保留「改为 GB/T 50378—2019（2024年版）」一句。
5. **措辞精简**：删「请修改设计说明，并在构造做法表注明分贝数」「需甲方决策」「提供厂家玻璃隔声性能检测报告」等追加句；图号尽量写具体编号。

**已由最终版验证的细则**（2026-11-10 臻玺宣府四专业校准，详见 `lessons-learned.md`）：

- 设计依据、标准版本更新类意见**不写条文号**（如「设计依据中《绿色建筑评价标准》应修改为 GB/T 50378—2019（2024年版）」）。
- 同一条文号下的多项指标**可合并为一条**，用「1、2、」编号，不违反「一条意见一个条款」（如 8.1.6 发电机烟气 + 油烟排放）。
- 「构造做法表补充」写成「设计说明及构造做法表补充」；图号写全（「0-AW-0002构造做法表」）。
- 引用标准带最新年号（GB/T 50034-2024、GB 20052-2024），不写无年号的旧版。
- 照抄建议书原文时**保留其原始表述**（含录入错字），不擅自润色；只有明显笔误影响理解时才做最小修正，并在 `review_log` 中注明。
6. **增删意见后必须重算「本页差错分类小计」，并补齐每行分类勾选**。用户最终版曾遗留 AI 版旧小计 10/2/16（实际 6/2/13）与第 10 条分类三列均未勾选 —— 交付前必须用 `verify_form.py` 查。

建议书原文存在录入错字（如 `G8 55038`、`10mg/m's`、`无量纲》`、`需提现`）与单位上标缺失时，做**最小修正**为正式写法（GB 55038-2025、mg/m³、无量纲、体现），不得借机追加内容。

## 4. 差错分类惯例

| 分类 | 适用情形 |
|---|---|
| **强条** | 涉《建筑环境通用规范》GB 55016、《住宅项目规范》GB 55038 的条款：禁烟 5.1.1、抗风压水密 4.1.5、栏杆 4.2.2.1、隔声 3.2.8.3/5.2.7、设备噪声 5.2.6、频闪 5.1.5、各层用水点压力计算书 7.1.7 |
| **法规** | 设计依据版本（GB/T 50378—2019 未注 2024 年版）、地方条例（垃圾分类 8.1.7 《深圳市生活垃圾分类管理条例》） |
| **图面** | 其余「设计说明增加 / 图纸表达 / 提供资料」类意见 |

参考模板已勾好的分类优先沿用（模板是旧项目已审单据，分类口径经过用户确认）。每行**恰好勾一个**分类。

## 5. 跨专业去重

| 条文 | 归口 | 其他专业处理 |
|---|---|---|
| 7.1.6 电梯节能 | 建筑（用户最终版第 11 条） | 电气不再重复 |
| 5.1.9 CO 浓度监测 | 暖通：改设计说明（300~400㎡、1.5~2.0m、联动阈值） | 电气：补平面图/系统图布置表达。两条角度不同可并存，但**交付时提示用户可择一**，若由暖通统一整改则删电气条 |
| 7.2.9 光伏 | 建筑：面积比例计算书 | 电气：布置图纸与系统图。交付物不同，可并存 |
| 设计依据 2024 年版 | 各专业分别按本专业图纸提 | 用户最终版建筑第 1 条明确保留此口径，不因重复而删 |
| 7.2.7.3 设备能效/节能评价值 | **按设备找图纸证据，三专业均可能已落实**：水泵→GB 19762 节能评价值不低于 2 级；风机→GB 19761 通风机能效 2 级（常附 >10000m³/h 单位风量耗功率＜0.27）；变压器→GB 20052-2024；照明→GB/T 50034-2024 | 图纸有等效表述即「已落实」，**该专业不提**；不按条文号在多个专业机械重复提。只有某专业图纸确实缺失时才在该专业补一条 |
| 8.2.2 海绵城市（年径流总量控制率等） | 海绵专项（用户负责，已满足） | 给排水不再提 |
| 5.2.6 排水噪声 33dB | 给排水 | 暖通 5.2.6 是建筑设备噪声，不同条文内容，不冲突 |

**跨专业核查口径（2026-11-10 用户确认）**：一条意见涉及多专业设备时（典型如 7.2.7.3），判定动作是**逐专业找证据**，不是逐专业补条。三专业图纸都有对应能效表述即全部视为落实、全部不提；只有证据缺失的那个专业才提。禁止为了"覆盖条文"而在已落实的专业重复出条。

**检索关键词**（在 `<专业>图纸文字.txt` 里 grep 即可定位）：`19762`、`19761`、`20052`、`节能评价值`、`能效等级`、`单位风量耗功率`、`6.2.8`、`7.2.7.1`。本项目实测：给排水命中「GB19762……不低于2级」，暖通命中「GB19761……2级」+「单位风量耗功率均小于0.27」，均在设计说明正文的中段条目（给排水第 7 条、暖通第 2 条），不在图面表格里。

建议书 3.2「图纸表达 / 设备表」类要求，**并入同条文号的设计说明意见**，不另起一条。

## 6. 技术数值修正（臻玺宣府校准值）

三星级节能**权衡计算负荷降低 5%**（设计建议 V3.1 原文写 8%，用户修订为 5%，以内审最终版为准）。

> 该数值是项目级校准，不是通用常量。新项目一律以该项目设计建议原文 / 最终版为准；若两者冲突，在交付说明中明确提示用户，不要擅自取 8% 或 5% 硬编码。

## 7. 内部台账（落实情况）与提资意见的区别

- **《绿建设计建议》「落实情况」列**：内部台账，排除项也如实标「需补充修改」，按证据判定，**不盲信原表预填的 ✓**（臻玺宣府原表 3 个预填 ✓ 中 3.2.8.1、4.1.5 与图纸不符，已修正）。
- **审图记录单**：提给设计院的指令，排除项不出现。
- 落实情况列宽通常仅约 2cm：单元格只写 ≤20 字精简结论（8pt），完整依据用 `doc_insert_markdown` 作为文末「附：落实情况备注说明」按条文号逐条列出。

## 8. 交付前自查清单

- [ ] 每条意见末尾有条文号，且一条只对应一个条款
- [ ] 无 5 类排除项，无计算书/使用部位/甲方决策/厂家报告等衍生要求
- [ ] 图纸已落实项已全部删除，模板旧数值/旧项目名/旧处理验证栏已清除
- [ ] 每条恰好勾一个分类（新增条目尤其容易漏勾）；小计 = 实际统计（强条 / 法规 / 图面）
- [ ] 表格已按实际条数收表，只留 1~2 行空白余量
- [ ] 处理、验证列为空；签署行只填审核人与日期
- [ ] 图号采用本项目图纸目录真实编号
- [ ] 跨专业重复项已在交付说明中提示用户择一
- [ ] 成品输出到项目根目录，未覆盖 `参考审图意见/` 下的同名归档件
